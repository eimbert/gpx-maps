# Logos de proveedores

Marcas utilizadas para identificar las conexiones de sus respectivos titulares. Recursos obtenidos de sus webs oficiales el 23/10/2026; no implican una certificación o patrocinio.

- `garmin.svg`: SVG de la cabecera de https://www.garmin.com/ (`gh__logo-container__logo__svg`).
- `polar.svg`: https://www.polar.com/welcome/img/polar-logo.svg
- `suunto.svg`: SVG de `.icon-suunto-logo` en el CSS oficial https://www.suunto.com/static/dist/assets/app-RbZ297Xh.css
- `wahoo.png`: https://cdn.wahooligan.com/wahoo-cloud/assets/release/wahoo-logo-black-236-58-9bded07caee5f586a3411969b78943c78146647b5fdf6ccdc2b4377b9d228fd6.png

La interfaz muestra Garmin, Polar y Wahoo en blanco mediante CSS sobre el fondo oscuro. Suunto conserva el triángulo rojo. Las imágenes mantienen sus proporciones y texto alternativo con el nombre de la marca.
